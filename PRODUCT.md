# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Developers exploring a portrait-oriented Babylon.js Lite and WebGPU sprite-game prototype in the browser. Players can also use the game as a complete, touch- and keyboard-operable stealth-and-gold experience.

## Product Purpose

Stealth and Steel is a playable stealth-and-gold game that serves as a practical reference for JavaScript, Vite, Tiled, and Babylon Lite game development. Success means preserving an understandable, functional game while making its systems and user interface suitable for real browser use.

## Positioning

This is a real portrait browser game with existing gameplay, settings, account/payment, progression, and Tiny Swords visual systems—not a static visual demo.

## Operating Context

The game runs in a browser through Vite, uses Babylon.js Lite and WebGPU rendering, and authors levels in Tiled. Development and evaluation include automated tests, a local browser preview, keyboard controls, and touch controls.

## Capabilities and Constraints

- Preserve existing gameplay, payment/account, progression, and settings behavior unless a scoped change explicitly modifies it.
- Support responsive portrait operation and keyboard/touch input.
- Keep WebGPU support and the existing browser-based runtime approach.
- The project uses JavaScript, Vite, Babylon.js Lite, Tiled, and a local BIS integration package.

## Brand Commitments

Preserve the Stealth and Steel name, supplied Tiny Swords visual assets, and the existing Stealth & Steel logo. User-reviewed visual measurements and interactions are binding for scoped UI work.

## Evidence on Hand

- [README.md](README.md) documents the game purpose, tooling, local run commands, and public demo.
- [Tiny Swords UI assets](STEALTH_STEEL/public/ui/tiny-swords) and the [Stealth & Steel logo](STEALTH_STEEL/public/ui/tiny-swords/stealth-and-steel-logo-transparent.png) are supplied project assets.
- Runtime source, automated tests, and Tiled-authored maps are present under `STEALTH_STEEL/`.

## Product Principles

- Preserve real gameplay and interaction while refining presentation.
- Make the browser game usable in portrait layouts with keyboard and touch.
- Reuse shared systems for visual and behavioral consistency.
- Ground product and visual claims in repository evidence and user review.

## Accessibility & Inclusion

Retain keyboard-operable controls, touch-operable targets, readable responsive UI, and accessible names independent of decorative artwork.
